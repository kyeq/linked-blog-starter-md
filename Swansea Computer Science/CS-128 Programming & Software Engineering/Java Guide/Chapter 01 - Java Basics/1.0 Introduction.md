# 1.0 Introduction
> [!info] From the CS-128 notes on Canvas — [open the original page](https://canvas.swansea.ac.uk/courses/68227/pages/1-dot-0-introduction)

In this chapter we're going to introduce the very basic concepts of writing and running a Java program - we'll get to the point where you can write a program that asks you your name and says hello to you - you'll be asked to extend that a bit in the exercises.

As will all chapters, in the [summary](https://canvas.swansea.ac.uk/courses/68227/pages/1-dot-10-summary-and-exercises) you'll find a self-test quiz: I'm not going to look at the marks you get for these (they definitely do not count towards your score for the module). But I will check to see if you're actually doing them.
