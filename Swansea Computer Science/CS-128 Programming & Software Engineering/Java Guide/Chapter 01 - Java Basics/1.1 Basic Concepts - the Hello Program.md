# 1.1 Basic Concepts - the Hello Program

***Make sure you have read [Chapter 0](https://canvas.swansea.ac.uk/courses/68227/modules/502598)on installing and running Java programs, and have a way of running Java so you can try the examples and exercises.***

In this chapter, we’ll look at some of the  *very basic*  concepts of programming and how they apply to Java. We’ll skip over some details – the point is to get the overall idea.

Programming is about systems that process input data and generate output results. The simplest ones simply read in input data, do something to it, and generate an output. The  *very*  simplest ones just generate some fixed output. For example, here’s the output of a program that just prints ‘Hello World!’ - the 'Hello World!' program has been, traditionally, the first one shown introducing a new language for around 50 years :

**>Hello World!**

(In the examples I show, output from computers will be  **bold**; input will be  *italic*  .)

In the 'Hello' example, the line:

```java
System.out.println("Hello World!");
```

is the one that actually generates the output. So what do all the others mean? They set up the necessary framework for the program to actually work – and we’ll skip most of the details for now – but see KEY POINT below.

### KEY POINT: Program Names & File Names

We can ignore  *most*  of the meaning of the lines  *for now*  (I promise I'll explain everything by the end of the module) - the only one that's important right now is this one:

```java
System.out.println("Hello World!");
```

**But one thing we do need to know is that in the line:**

```java
public class HelloWorld {
```

**“HelloWorld “ is the name of the program.**  And this program  ***MUST***  be saved in a file called  **HelloWorld.java**  -  *and to be safe* with that  *EXACT case: so not helloworld.java, or HELLOWORLD.java (though they may work in some operating systems) or any other combination except HelloWorld.java.*

Make sure you know and understand the following points.

- *You can call a program whatever you want*  – the computer pays no attention really and does not care.  *The most important point is that it is meaningful*   *to people*  . Calling a program “Lemon” will work, but it won’t help someone reading the program to understand it.
- *There are also some conventions on how you should name things in Java*  – we’ll get back to this later on but for now stick to letters and digits –  *you cannot put spaces in names*  .
- *Case matters*  - depending on what computer operating system you are using the case of the filename  ***might***  not have to match the case of the identifier (i.e. you  ***might***  be able to call your program “HelloWorld” and store it in a file called “helloworld.java” – but it is  *always safer*  if they match). So in this case, your code should be in a file called “HelloWorld.java” – note the capital H and W.
- *The name*  HelloWorld  *is an  **identifier***  – see below.

### Compiling and Running Java

You should read [chapter 0](https://canvas.swansea.ac.uk/courses/68227/modules/502598) for more information on compiling and running Java programs but briefly:

- **Compiling**  - the text you write is not directly executed by the computer: first it's turned into an executable form by a program called a compiler. In Java, the compiler is called 'javac'.
- **Executing**  - once compiled, a new file called the class file will be created. This can be executed by the java environment - using the command 'java'.

Once you've created and saved your program you should be able to see it in your computer's file system (assuming we called our program file  **Hello.java** ):

*(image on Canvas: Source code only)*

To compile the Hello World program - assuming you've followed the instructions in [Chapter 0](https://canvas.swansea.ac.uk/courses/68227/modules/502598), you can just type:

**javac HelloWorld.java**

Now you will be able to see the class file that's been created:

*(image on Canvas: Source and compiled code)*

If you type:

**java HelloWorld**

(note do  *not*  add '.class') the program should run and print out "Hello World!" on your screen.

#### Doing this with Fewer Steps

Since Java version 11 it's been possible to skip the first step and just write

**java HelloWorld.java**

This does both the steps above - compiles the code and then runs it. So why didn't I tell you this earlier?

- I  *really* want you to understand that there are  *two* steps here - compiling and running.
- I hope quite soon you are going to move away from programming like this and start to use an [IDE](https://canvas.swansea.ac.uk/courses/68227/pages/0-dot-9-getting-and-using-intellij) - which will do a lot of the routine work for you.
