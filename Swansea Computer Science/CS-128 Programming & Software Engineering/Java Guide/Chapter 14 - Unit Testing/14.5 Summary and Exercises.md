# 14.5 Summary and Exercises
> [!info] From the CS-128 notes on Canvas — [open the original page](https://canvas.swansea.ac.uk/courses/68227/pages/14-dot-5-summary-and-exercises)

In this chapter we looked at how to use JUnit to implement  *unit tests.*

### Exercises

1. Download the version of [BankAccount](https://canvas.swansea.ac.uk/courses/68227/files/11393116) from the end of Chapter 13, and the create JUnit tests for it.
2. Download the version of [Bank](https://canvas.swansea.ac.uk/courses/68227/files/11393115) from the end of Chapter 13, and recreate the bug in the video in [14.4](https://canvas.swansea.ac.uk/courses/68227/pages/14-dot-4-junit-basics) in the tests.
3. Fix the bug - you may want to replace the stream based code in getAccount with something more like the code you are used to (have a look at the version of [Bank](https://canvas.swansea.ac.uk/courses/68227/files/11333953) in Chapter 12) to get an idea of what to do.
