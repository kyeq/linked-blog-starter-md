# 14.2 IntelliJ Coverage
> [!info] From the CS-128 notes on Canvas — [open the original page](https://canvas.swansea.ac.uk/courses/68227/pages/14-dot-2-intellij-coverage)

Before we get into unit testing and JUnit, here's a video that shows in more detail how IntelliJ's  *coverage* tools can show you how much of your code you have tested. It's based on the bank example, but it has an extended test class:

```java
class TestBank {

    public static void main(String[] args) {
        Bank testBank = new Bank();

        System.out.println("Create new accounts and adds them to the bank");
        BankAccount testAccount = new BankAccount("Bob", 100);
        testBank.addAccount(testAccount);
        testBank.addAccount(new BankAccount("Mary"));
        System.out.println(testBank);
        System.out.println(testBank.totalAmount());

        System.out.println("Get the account for Mary and add 100");
        BankAccount mary = testBank.getAccount("Mary");
        mary.depositMoney(100);

        System.out.println("Try to delete Mary - should be false as account not empty");
        System.out.println(testBank.deleteAccount(mary));

        System.out.println("Try to withdraw 100 for Mary - should fail, she only has 100");
        System.out.println(mary.withdrawMoney(200));

        System.out.println("Withdraw all Mary's money and try to delete Mary - should work");
        System.out.println(mary.withdrawMoney(100));
        System.out.println(testBank.deleteAccount(mary));
    }
}
```

The video shows how additional tests increase the amount of the code that has been tested (the  *coverage* ) and how you can see which parts have/have not been executed. This is NOT instead of unit testing - and later we will show how we can use it to check that our unit tests do actually properly cover our code.
