# 5.2 Summary
> [!info] From the CS-128 notes on Canvas — [open the original page](https://canvas.swansea.ac.uk/courses/68227/pages/5-dot-2-summary)

In this chapter, we looked at the concept of scope - where in a programme a variable can be 'seen.

- We saw that a variable is visible to all the code inside the block in which it is declared - a block is the code within curly brackets {..}.
- This includes any blocks inside the one they are declared in.
- Two variables can have the same name if they are not declared inside the same blocks as long as one of those blocks is not inside the other one.
- If one block is inside another block, you cannot declare a variable in the inner one with the same name as one declared in (or visible in) the outer one.
