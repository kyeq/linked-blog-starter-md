# 0.2 Install Java Tools on Your Own Machine - Windows
> [!info] From the CS-128 notes on Canvas — [open the original page](https://canvas.swansea.ac.uk/courses/68227/pages/0-dot-2-install-java-tools-on-your-own-machine-windows)

### Java on Your Own Machine - Windows

First download and install Java as explained in [section 0.1](https://canvas.swansea.ac.uk/courses/68227/pages/0-dot-1-running-and-installing-java)

**This is the most basic way to run Java on Windows - but even if you have programming experience you should be able to do this.**

- It makes it clear that Java is a fully-compiled language (unlike, say, Python) - where you first  *compile* the code(translate it to a machine-readable form) and then (separately) run it.
- It's always good to know how to do this as a fall-back option (this way is guaranteed to work on the University lab machines for example).

### Something to Configure First

Here's something I think all Computer Scientists should change in the way Windows works on their computers:

> [!note] There is a video for this on the Canvas page.

#### **Notepad++**

As well as being able to run Java programs, you also need to be able to  *edit*  them. There are lots of text editors available but one of the most commonly used is Notepad++. If you want to use a different one, that's fine - there are free (and not free) alternatives however Notepad++ is installed in the labs. But do NOT try to use something like Word (it won't work); and although the built-in NotePad will work, it will be awful (a good editor like Notepad++ is  *syntax aware* - it knows you are editing a Java program and it will help you, by colouring different words for example).

You may feel that you have enough experience to bypass this way of writing Java programs and move straight to something more advanced - that's fine, but I still recommend you have a good text editor like Notepad++ as it's likely to come in handy.

Either [download Notepad++](https://notepad-plus-plus.org/downloads/) or Google 'Notepad++' - this will take you to a list of downloads - just choose the top one (the latest version - it was 8.8 when I wrote this). Then scroll down until you get to 'Download 64-bit x64' (if you have an Intel/AMD machine) or 'Download ARM64' (if you have an ARM/snapdragon machine) then click 'Installer'. Then run the installer as normal.

#### **Don't like Notepad++?**

There are alternatives available - and you're free to use them but remember they are unlikely to be installed on the University lab machines. ALSO REMEMBER that the point of this is so you can learn the most basic way of running Java - so something snazzy that does that for you isn't a good idea at this point.

### At this point...

...you should be able to write, compile and run Java programs as described in [section 0.5](https://canvas.swansea.ac.uk/courses/68227/pages/0-dot-5-java-command-line-basics-windows) - but please don't just use these basic tools for more than the first couple of weeks - once you have got used to them, [move on to something more advanced](https://canvas.swansea.ac.uk/courses/68227/pages/0-dot-7-more-advanced-tools-what-are-they-and-which-to-pick).

### Don't get too comfortable...

...using Notepad++ - it's good for getting the idea of how Java programs are written and run, but - once you've got the point that writing/running Java is a two-stage process - you will make life a lot easier for yourself if you move on to something better in a couple of weeks at most.
