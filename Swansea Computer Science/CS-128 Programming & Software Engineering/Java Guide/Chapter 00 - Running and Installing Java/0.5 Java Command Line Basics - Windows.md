# 0.5 Java Command Line Basics - Windows
> [!info] From the CS-128 notes on Canvas — [open the original page](https://canvas.swansea.ac.uk/courses/68227/pages/0-dot-5-java-command-line-basics-windows)

### Getting Started with Running Java

*This page assumes you are using the command line and Notepad++ - not something more advanced.  **But even if you are, you should still know how to do this**  - a basic understanding of "what is going on" is important (and more advanced tools hide this from you).*

To start with, we're going to run Java from the command line - we're going to use a text editor to write out code and the command console to compile and run programs.

**Although you may think it's 'old fashioned' the command line is an ESSENTIAL tool in software development - it's often quicker, and it can be  *scripted* meaning it is  *way* more powerful than the standard graphical interface. You absolutely need to be able to use it if you want to go into software development. (For example, for my second year course, if you want to check that your coursework works before you submit it - and you absolutely do - then you need the command line).**

There are more sophisticated tools that we'll introduce next - but for now it's essential that you understand what's going on. To start with you need to know how the command line works in Windows so you can navigate it and find your files - and understand how it interacts with Windows Explorer (which you probably have used before).

The video below introduces the very basic commands you will need for this module - the command line can do much more, and it will be worth your time to learn to use it (there's a tutorial [here](https://www.bleepingcomputer.com/tutorials/windows-command-prompt-introduction) - one of many). However you do not absolutely need to do this right now (but make sure you do at some point). I introduced how to open the cmd window in the section on installing Java for Windows (the video to check you have installed Java correctly) - but you can just type 'cmd' in the search box and one of the results will be 'Command Prompt' - which is the one you want (if you want to use the more modern 'terminal' - or 'power shell' - you can, but it makes no real difference here).

> [!note] There is a video for this on the Canvas page.

### Compiling and Running Java

- A Java program starts off as just an ordinary file - with a name ending in  **.java**  - which you write with a text editor (on Windows normally Notepad++).
- To turn that into something that can be executed it must be compiled - compiling and running programs are two separate steps.
- Compiling - in Java using the  **javac**  command - compiles the program and if there are no errors (and to start with there usually are) it generates a new file ending  **.class.**

Watch the video below to understand how to do this - the program that we write in this (the 'Hello' program) is explained in detail in Chapter 1: for now, we're just showing how to write and run it: we write it with an editor (in this case Notepad++); we then compile it (turn it into a runnable program) using the command  **javac *;*** then we actually run it with the command  **java.**
