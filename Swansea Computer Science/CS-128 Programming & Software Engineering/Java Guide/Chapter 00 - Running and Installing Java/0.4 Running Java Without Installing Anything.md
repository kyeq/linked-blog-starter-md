# 0.4 Running Java Without Installing Anything
> [!info] From the CS-128 notes on Canvas — [open the original page](https://canvas.swansea.ac.uk/courses/68227/pages/0-dot-4-running-java-without-installing-anything)

Sometimes you might need to write code without access to a machine with the tools you normally use, and there are some online options. They are all much the same and pretty obvious to use - OnlineGDB has a debugger but you will only be writing simple programs if you need to do this, so this isn't a big advantage:

- [OnlineGDB](https://www.onlinegdb.com)
- [JDoodle](https://www.jdoodle.com/online-java-compiler/)
- [IDEOne](https://ideone.com)
- [Online-IDE](https://www.online-ide.com/#google_vignette)

**I don't recommend using these normally but I DO recommend knowing how to use at least one of them - as a fallback option in the January in-class test.**

#### Accessing University Computers Remotely

***This can be handy at times**  - remote access to lab PCs was set up for COVID-19 - so although it still works as I write this, and I have no reason to think it won't keep working, it's always possible that if the service is not used enough, it will be withdrawn.*  This approach means you are directly using and [connecting to computers in the University PC labs](https://canvas.swansea.ac.uk/courses/68227/pages/accessing-university-computers-remotely). You'll also need to know [how to use the University PC machines](https://canvas.swansea.ac.uk/courses/68227/pages/using-university-pc-lab-machines)for Java ( *slightly* different to using your own machine).
