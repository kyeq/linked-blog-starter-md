# 0.8 DANGER - Packages
> [!info] From the CS-128 notes on Canvas — [open the original page](https://canvas.swansea.ac.uk/courses/68227/pages/0-dot-8-danger-packages)

**If you follow the guidance in the videos in the [next section about IntelliJ](https://canvas.swansea.ac.uk/courses/68227/pages/0-dot-9-getting-and-using-intellij) this should not happen - but sometimes people don't follow the instructions and have some trouble with this - here's how to fix it should you need to.**

Java allows you to structure your code using something called  *packages.* Packages are very helpful when you want to organise things. So, for example, when you type (which you will soon):

```java
import java.util.Scanner;
```

Scanner is actually in a package called java.util.

To put something a package we put a line like this at the top:

```java
package mypackagename;
```

(there are rules about package names which we'll skip).

The trouble is that - while great - packages complicate things right now and we don't want them - but tools like IntelliJ want to put them in for you.

Here's how to fix that (read/watch the next section first).
