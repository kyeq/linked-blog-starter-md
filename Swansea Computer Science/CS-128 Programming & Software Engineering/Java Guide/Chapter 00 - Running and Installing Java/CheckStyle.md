# CheckStyle
> [!info] From the CS-128 notes on Canvas — [open the original page](https://canvas.swansea.ac.uk/courses/68227/pages/checkstyle)

Here are the files you need to use the  *checkstyle* program from [Section 0.10](https://canvas.swansea.ac.uk/courses/68227/pages/0-dot-10-using-checkstyle) to check you are not making style errors.

- [checkstyle](https://canvas.swansea.ac.uk/courses/68227/files/11334131) - the actual program.
- [inlinebrackets.xml](https://canvas.swansea.ac.uk/courses/68227/files/11334253) - the style file for the bracketing style I use (note you will be given a slightly different version of this - also used by Autograder - for the coursework).
- [separatebrackets.xml](https://canvas.swansea.ac.uk/courses/68227/files/11334228)- the style file if you put all brackets on a line of their own (note you will be given a slightly different version of this - also used by Autograder - for the coursework).
