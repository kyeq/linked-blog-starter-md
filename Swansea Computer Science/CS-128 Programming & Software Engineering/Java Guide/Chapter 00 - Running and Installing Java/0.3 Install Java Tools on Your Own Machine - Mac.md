# 0.3 Install Java Tools on Your Own Machine - Mac
> [!info] From the CS-128 notes on Canvas — [open the original page](https://canvas.swansea.ac.uk/courses/68227/pages/0-dot-3-install-java-tools-on-your-own-machine-mac)

### Java on Your Own Machine - Mac

#### **You Might Already Have Java...**

It's  *possible*  you already have Java. To check first open the  *Terminal* - the video show how: it's in the Utilities folder inside your Applications folder. Then type (remember to type newline/return at the end):

```java
/usr/libexec/java_home -V
```

You have to do this  *exactly - the only space in the command is before the -.* If it says you have a version of Java 8 or later (it will say "SE 17" or "SE 21" for example in the line), then type this:

```java
javac -version
```

If it says something like javac xxx you already have a version and you can skip the installing  *provided* it says you have 17, 21 or 25; if it says it can't find the command then you need to install java as shown below. If you did find a version of java when you typed the 'java_home' command (and it's 17, 21 or 25), then follow the instructions  *after*  the sections below on getting and installing Java. If you found that the version of Java was was not one of 17, 21 or 25, then install one using one of the options below, and follow the guidance in the section ' **Already Had Java and Installed One Too?** ' below.

**Remember, you need to get one of: Java 25, Java 21 or Java 17 - NOT any other version!**

#### **Already Had Java and Installed One Too?**

**If you found that you had a version of Java already installed AND you installed a new one: type:**

```java
java -version
```

and

```java
javac -version
```

(notice these are NOT exactly the same). Both of them should return the same number, and it should be the number of the version you just installed. If either the numbers are different, or they show the number of the version you originally had, then you need to type this:

```java
sudo rm -rf /Library/Java/JavaVirtualMachines/jdk<number>.jdk
```

(after which it will ask you for your password) where you should replace <number> by the version number you wanted to remove. For example, for me, when I typed:

```java
javac -version
```

It responded with:

```java
javac 1.8.0_201
```

Which is not the one I wanted (I'd just installed 17.0.7). So I typed:

```java
sudo rm -rf /Library/Java/JavaVirtualMachines/jdk1.8.0_201.jdk
```

After that, type the java -version and javac -version commands again; you should find they are the same, and the version you just installed.

#### **BBEdit**

As well as being able to run Java programs, you also need to be able to  *edit*  them. There are lots of text editors available but a commonly used one is BBEdit - this has both a free and a paid version (the free version is absolutely fine; I've been using it for years - it's not worth the money you pay for the extra features - which are mainly for HTML - for this module). If you want to use a different one, that's fine - there are free (and not free) alternatives. But do NOT try to use something like Word (it won't work); and although the built-in TextPad will work, it will be awful (a good editor like BBEdit is  *syntax aware*  - one it knows you are editing a Java program it will help you, by colouring different words for example).

**REMEMBER part of the point of doing this this is to learn that writing/running Java is a two stage process, so some snazzy tool that hides that isn't so useful here (which is why I recommend BBEdit).**

You may feel you already know enough about programming to skip using these basic tools - that's fine but I still recommend you install a good text editor as they often come in handy.

Either go here to [download BBEdit](http://www.barebones.com/products/bbedit/index.html).
