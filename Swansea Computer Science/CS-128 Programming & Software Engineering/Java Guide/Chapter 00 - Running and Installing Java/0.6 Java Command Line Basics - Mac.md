# 0.6 Java Command Line Basics - Mac

### Getting Started with Running Java

*This page assumes you are using the terminal and BBEdit - not something more advanced.  **But even if you are, you should still know how to do this**  - a basic understanding of "what is going on" is important (and more advanced tools hide this from you).*

To start with, we're going to run Java from the command line, or  *terminal*  on a Mac - we're going to use a text editor to write out code and the command console to compile and run programs.

**Although you may think it's 'old fashioned' the terminal is an ESSENTIAL tool in software development - it's often quicker, and it can be  *scripted* meaning it is  *way* more powerful than the standard graphical interface. You absolutely need to be able to use it if you want to go into software development. (For example, for my second year course, if you want to check that your coursework works before you submit it - and you absolutely do - then you need the terminal).**

There are more sophisticated tools that we'll introduce next - but for now it's essential that you understand what's going on. To start with you need to know how the Terminal works on a Mac so you can navigate it and find your files - and understand how it interacts with the Finder (which you probably have used before).

The video below introduces the very basic commands you will need for this module - the command line can do much more, and it will be worth your time to learn to use it (there's a tutorial [here](https://ubuntu.com/tutorials/command-line-for-beginners#4-creating-folders-and-files) - it's for Linux but essentially the same from the point I've linked - section 4 - onwards). However you do not absolutely need to do this right now - but you absolutely DO have to do it at some point.

> [!note] There is a video for this on the Canvas page.

### Compiling and Running Java

- A Java program starts off as just an ordinary file - with a name ending in  **.java**  - which you write with a text editor (on a Mac normally one called BBEdit).
- To turn that into something that can be executed it must be compiled - compiling and running programs are two separate steps.
- Compiling - in Java using the  **javac**  command - compiles the program and if there are no errors (and to start with there usually are) it generates a new file ending  **.class.**

Watch the video below to understand how to do this - the program that we write in this (the 'Hello' program) is explained in detail in Chapter 1: for now, we're just showing how to write and run it: we write it with an editor (in this case Notepad++); we then compile it (turn it into a runnable program) using the command  **javac *;*** then we actually run it with the command  **java.**
