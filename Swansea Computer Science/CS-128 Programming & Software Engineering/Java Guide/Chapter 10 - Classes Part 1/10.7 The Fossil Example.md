Before the video, here's a quick summary of the 'process'.

- Create a new empty class.
- DON'T write a 'main' method - if you use Netbeans etc. and it puts one in for you, DELETE IT.
- You may have to rewrite the 'main' method later  *but for now don't confuse yourself.*
- Decide on what data you want and write in variable declarations for them.
- Make sure the variable are private.
- The variables should NOT be inside methods.
- Once you have your variables write the methods you need to set them (names starting 'set') and get (names starting 'get) them.
- E.g. looking at just one variable and the methods that go with it - if you have a variable called streetName the first thing you might want to write is a method to set it:

```java
private String streetName;
...
public void setStreetName(String name){
    streetName = name;}public String getStreetName() {
    return streetName;
}
```

You might need other methods too, and you will also need usually one or more  *constructors* (which are the first thing in [chapter 11](https://canvas.swansea.ac.uk/courses/68227/pages/11-dot-1-constructors)); also you may not always need all the get and set methods.
