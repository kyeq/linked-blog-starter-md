# Circle Example-2
> [!info] From the CS-128 notes on Canvas — [open the original page](https://canvas.swansea.ac.uk/courses/68227/pages/circle-example-2)

This is an example of using OO to represent a circle (or circles). The first one is non-oo and shows how all the details of implementation are visible; how data about one circle gets spread across multiple data structures (arrays in this case); and how it's just generally bad... The next two show how we can create a class called Circle that hold all information about and knows how to compute everything about a circle; then OOCircle just uses this class to create and manipulate circle objects without having to know anything about  *how*  this is done.
