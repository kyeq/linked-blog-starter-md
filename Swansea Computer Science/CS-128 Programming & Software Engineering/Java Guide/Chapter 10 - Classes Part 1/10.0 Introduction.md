# 10.0 Introduction
> [!info] From the CS-128 notes on Canvas — [open the original page](https://canvas.swansea.ac.uk/courses/68227/pages/10-dot-0-introduction)

In this chapter we're going to introduce the idea of Object Orientation.

- We're going to start with the idea of simply trying to group related data together.
- We'll move on to trying to ensure that this data is correctly and consistently set.
- We'll end this chapter looking at how we can stop our efforts to set data correctly being subverted, and begin to see the underlying idea of OO programming and how it helps to make software more reliable and re-usable.
