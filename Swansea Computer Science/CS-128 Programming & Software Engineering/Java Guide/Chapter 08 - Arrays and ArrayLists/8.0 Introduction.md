# 8.0 Introduction
> [!info] From the CS-128 notes on Canvas — [open the original page](https://canvas.swansea.ac.uk/courses/68227/pages/8-dot-0-introduction)

In this chapter we'll look at how we can create  *lists* of data:

- **Arrays**  - which are simple and useful when you know how many data items are in your list, the order does not change, and you don't want to remove/add things except perhaps at the end. They are particularly useful when you have a fixed list of data.
- **ArrayLists**  - these are more complex but more flexible, and let you make changes more easily. You also don't need to know how much data they will contain when you create them.
