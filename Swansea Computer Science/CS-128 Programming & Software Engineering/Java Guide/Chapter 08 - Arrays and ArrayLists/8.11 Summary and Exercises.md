In this chapter we looked at Arrays and ArrayLists. We also looked at For-Each loops.

### Arrays

- An array is a fixed-sized list of data, all of the same type (e.g. all int or all String). An array is relatively simple but:
- It's not possible to change its size once created (you need to create a new larger array and copy the data to it) - this can be a problem if you run out of space.
- If you want to insert a new data item between existing items, you need to move all the existing data items to make space.
- If you want to delete an item, you also need to move existing items if you want to keep them in the same order.
- Arrays are most useful when you have a fixed set of constant data which won't change.
- If you want to, say, check if an item is in an array, you need to check each element (if the items are in order you can speed this up - as you'll see later in your degree - using the  *binary search algorithm* ).
- They are also useful when you know you will only be adding new data to the end; you know there is a limit to how much data you will add; and you will not need to delete data.

### ArrayLists

- An ArrayList is a more complex data structure - one of several in Java - which needs more resources (in computing time and memory). However:
- An ArrayList has no fixed size and can grow as large as you need (within reason).
- It is easy to check if an item is present in an ArrayList.
- You can remove items and add items from within an ArrayList without having to write code to move the other items.
- ArrayLists are more useful when you do not know how much data you will have; that data may arrive in any order (and may also need to be deleted). They also make it easy if you need to keep the data in a particular order (e.g. alphabetically sorted).

### For-Each Loops

The For-Each loop is a more abstract version of the for loop. It is mainly useful for processing lists of data (arrays, ArrayLists etc.). It does not specify how you should process the list - unlike a for loop which traditionally explicitly creates a variable to step through the list; checks if it's equal to the size of the list; and then increments it every time the loop is executed. Instead a For-Each loop specifies what needs to happen - and Java is left to construct the implementation, meaning you need to make fewer changes to your code as it evolves over time.
