# Books Examples
> [!info] From the CS-128 notes on Canvas — [open the original page](https://canvas.swansea.ac.uk/courses/68227/pages/books-examples)

Examples based on arrays and ArrayLists of books - remember:

- If the number of data items is fixed and the order won't change (or it is all constant to start with) then arrays are good
- If the number changes, the order changes, or you need to insert or delete from the list, then ArrayList is much better
