# 4.10 Summary and Exercises
> [!info] From the CS-128 notes on Canvas — [open the original page](https://canvas.swansea.ac.uk/courses/68227/pages/4-dot-10-summary-and-exercises)

In this chapter we looked at two main ways of executing code conditionally - that is doing something (perhaps one of a number or possible things) based on a condition: we execute the code if the condition is true; and not if it is false.

*If statements*  first check a condition then execute code if that condition is true - these can be combined with  *else statements* , which execute code if the conditions is false. If statements can be extended to include multiple conditions.

We also saw  *switch statements*  which are useful for choosing one of a number of possible options; and - as an advanced option - introduced  *ternary operators.*

We also started to look at the problem of  *testing -* and why it is difficult. We introduced  *graphs* - specifically  *control flow graphs* or  *program graphs -* to start to get an idea of how unnecessarily complex our programs can get if we don't design them well (remember  *don't get sucked in* ). We also looked at  *test coverage* and the basics of choosing test cases.
