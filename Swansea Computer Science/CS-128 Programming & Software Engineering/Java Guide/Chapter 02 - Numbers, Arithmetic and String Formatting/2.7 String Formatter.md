# 2.7 String Formatter
> [!info] From the CS-128 notes on Canvas — [open the original page](https://canvas.swansea.ac.uk/courses/68227/pages/2-dot-7-string-formatter)

Let's look again at the one of the swimming pool programs:

```java
/* Program to compute the cost of excavating a pool
   This is the second version using a final value for
   the excavation costs per cubic metre
*/
public class PoolExcavationCosts2 {     static final int EXC_COST_PER_CUBIC_METRE = 20;
     public static void main(String[] args) {

          int depth = 2;
          int width = 4;
          int length = 7;

          //Now calculate the volume
          int volume = depth * width * length;

          //Print it out - volume should be 56
          System.out.println("Depth: " + depth +
                          " Width: " + width +
                          " Length: " + length);

          System.out.println("Volume: " + volume);

          int cost = volume * EXC_COST_PER_CUBIC_METRE;

          //Should be 1120
          System.out.println("Cost: " + cost);
     }
}
```

Now, remember what we said about constants and translating a program into another language? The trouble with the code above is that because we are using '+' to join strings, the actual output of the program is broken into many small strings: e.g. 'Depth', 'Width' etc. So if we wanted to make all these constants, we would need - in this case - five when there are only three lines of output. This is annoying.

A convenient way to avoid this is to use  *String Formatter*  - this comes in a variety of versions, and I'm only going to talk about one.

Here's a simple example:

```java
String name = "Ada Lovelace";
String yourName = String.format("Your name is %s", name);
System.out.println(yourName);
```

The output of this is "Your name is Ada Lovelace" - and the  **%s**  is a 'placeholder' in the string 'Your name is %s' that is replaced by the value in the variable 'name'.

It is actually more powerful than this - you can have  *multiple* placeholders and they do not just have to be strings: For example:

```java
String name = "Ada Lovelace";
int yearOfBirth = 1815;
String yourName = String.format("Your name is %s and you were born in %d",
    name, yearOfBirth);
```

Now there are  *two* variables in the output - a String (with 'placeholder'  **%s** ) and an integer (with a  **%d**  - for 'decimal'). You can have as many as you want and they will replace the placeholders - by default - in the order they appear. If the type of the variable and the placeholder don't match (e.g. if you swap the  **%d**  and the  **%s**  above) then you'll get an error.

There are actually many possible placeholders - in practice, you'll find  **%s**  and  **%d**  the most useful. You will also find that you can add  *modifiers* to the placeholders to control for example, how many spaces are used for a particular output; how many decimal places are printed for a double; the order of the replacement of placeholders by variables. I'll leave researching these as an exercise - there are many examples if you search - but we'll look at one more thing you can do. It's possible to insert  *newline* characters into strings by using the  *escape sequence*  **\n .** So we can split our output in our example above over two lines:

```java
String name = "Ada Lovelace";
int yearOfBirth = 1815;
String yourName = String.format("Your name is %s\n You were born in %d",
    name, yearOfBirth);
```

Now the string 'Your name is Ada Lovelace' appears on one line, and 'You were born in 1815' on the next. So if we now look at our example program at the top of the page, we can change it to this:

```java
/* Program to compute the cost of excavating a pool
	 This is the second version using a final value for
	 the excavation costs per cubic metre
*/
public class PoolExcavationCosts2 {        static final int EXC_COST_PER_CUBIC_METRE = 20;
	public static void main(String[] args) {

		int depth = 2;
		int width = 4;
		int length = 7;

		//Now calculate the volume
		int volume = depth * width * length;

		//Print it out - volume should be 56
		int cost = volume * EXC_COST_PER_CUBIC_METRE;
		String output = String.format("Depth: %d Width %d Length %d\nVolume %d\nCost %d",
				depth, width, length, volume, cost);

		System.out.println(output);
	}
}
```

Now instead of having to use  *five* constants we only need one:

```java
/* Program to compute the cost of excavating a pool
	 This is the second version using a final value for
	 the excavation costs per cubic metre
*/
public class PoolExcavationCosts2 {        static final int EXC_COST_PER_CUBIC_METRE = 20;        static final String OUTPUT_MESSAGE = "Depth: %d Width %d Length %d\nVolume %d\nCost %d";
	public static void main(String[] args) {
		int depth = 2;
		int width = 4;
		int length = 7;

		//Now calculate the volume
		int volume = depth * width * length;

		//Print it out - volume should be 56
		int cost = volume * EXC_COST_PER_CUBIC_METRE;
		String output = String.format(OUTPUT_MESSAGE,
				depth, width, length, volume, cost);

		System.out.println(output);
	}
}
```

Which would make it a lot easier if, say, we wanted to produce a version of our program that worked in multiple languages.

### 2.7.1 Controlling Output - Important for Coursework

As well as **%d a** nd  **%s**  there are many other  *format specificers* you can use - and. you can  *configure* them too. The most common thing you might want to do, is control the number of decimal places in output. For example:

```java
System.out.println(1.0/3); //Prints 0.33333333333.... - why did we write 1.0???
```

Which is not great - normally we would want to control the number of decimal places. We could do that by  *rounding* the number - but there is a 'nicer' way. Don't round (i.e change) the output - just say how many decimal places you want.

```java
String myOutput = String.format("To 2dp: %.2f", 1.0/3);System.out.print(mOutput); //You can just write String.out.format("To 2dp: %.2f", 1.0/3);
```

This uses  **%f**  -  *floating -* to say we are going to output a floating-point number (works with double too), and the  **.2**  between the  **%**  and the  **f**  specifies we don't care how about the output  *before* the decimal point, but we only want two decimal places  *after* it.

**Exercise** - find out what else you can do with %f

#### Advanced Aside: \n vs %n

In the example above we used the sequence  **\n**  to represent the  **newline**  character. This is a common  *escape sequence* used to represent a character that is otherwise not easy to write - by putting the '\' in front of a 'normal' character. Sometimes you will see, instead, suggestions that you should use %n instead with claims it's more 'system independent'. Technically this is true but it also comes with some serious downsides that are not obvious and beyond this module, so  *I do not really recommend using this.*

More usefully, there are other escape sequences you can use too - for example ' **\t** ' represents a  *tab*  character.
