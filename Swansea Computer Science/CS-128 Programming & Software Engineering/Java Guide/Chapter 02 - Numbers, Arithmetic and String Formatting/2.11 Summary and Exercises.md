# 2.11 Summary and Exercises
> [!info] From the CS-128 notes on Canvas — [open the original page](https://canvas.swansea.ac.uk/courses/68227/pages/2-dot-11-summary-and-exercises)

You can find the example programs from this chapter, and others that are related to the material in this chapter below this page in Canvas.

- In this chapter, we've looked at basic calculations, and how to build a program that computes a result from multiple input, by performing - and combining - multiple calculations.
- We've seen that it's always best to break a problem down into parts before trying to program it, and to program - and test - each part separately. That way, you can tell they all work before trying to combine them.
- We've also seen how to input numbers, and the importance of using constants (final variables) as well as final variables that are  *not* constants, to make our programs easier to understand and update.
- We introduced the concept of a string formatter.
- We introduced the concept of  *refactoring -* and explained the importance of continually trying to improve our code.

#### Exercises

You should try to write similar programs to the one in this chapter as exercises - if you can't think of any, here are a few suggestions (in most cases, you should work out the calculations you need to perform  *before* you start writing your program):

- **Square and Cube:**  write a program that reads in a number and outputs its square and cube.
- Calories Burned. Your  *basal metabolic rate* is how many calories (technically kilocalories) you use without doing any exercise to maintain your current weight. An  *approximation* of this is:
		- for everyone to start with: 10 times your weight in kilos plus 6.25 times your height in centimetres minus 5 times your age in years.
		- for women: subtract 161.
		- for men: add 5.

Write a program to work out the basal metabolic rate given height, weight and age (for now work it out for both a man and a woman).

- Assume a person walks some distance every day and uses more calories. Extend your program above to work out how many calories in total they use (including the calculation from the exercise above - i.e. add the results together) if they walk a specified number of kilometres. You can assume that 10000 steps uses 500 calories; and a kilometre is about 2000 steps (actually that's a bit high for most people but it's only an approximation).
- S **hipping Container:**  You need to ship a number of boxes of a given width, length and height, and you need to know how many shipping containers you need to do that. A standard 40 foot shipping container has a volume of about 67m2. Write a program that reads in the width, length and height of the boxes (in metres) as well as the number of boxes, and computes the number of containers needed. (In real life the shape of the boxes will be a factor too, and you might not be able to use all the space in a container - but ignore that here.) This problem is a bit more complex than the others - remember to break your problem down into simpler parts. (Also, where could you use constants in this program?)
- **Heavy Shipping Containers:**  As well as size, you might want to consider weight. A standard shipping container can carry about 26 000Kg. Extend your program so it also inputs the weight of a box, and make sure that the number of containers you calculate takes this into account. So a few heavy boxes might easily fit, but overload the container - in that case, you need to increase the number of containers even though they are not full.
