# 2.0 Introduction
> [!info] From the CS-128 notes on Canvas — [open the original page](https://canvas.swansea.ac.uk/courses/68227/pages/2-dot-0-introduction)

In this chapter we'll look at basic arithmetic in Java, and how to write a straight line program that performs a calculation but does not make any decisions, or include any loops (that will come later). We'll build an example in stages (to estimate the cost of a swimming pool).

As will all chapters, in the summary you'll find a self-test quiz: I'm not going to look at the marks you get for these (they definitely do not count towards your score for the module). But I will check to see if you're actually doing them.

Also at the end of this chapter you'll find a few exercises for you to attempt - please do so as you need to practice to become a good programmer.
