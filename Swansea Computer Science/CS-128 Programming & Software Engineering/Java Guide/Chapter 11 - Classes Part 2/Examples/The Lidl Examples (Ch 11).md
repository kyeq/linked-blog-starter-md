# The Lidl Examples
> [!info] From the CS-128 notes on Canvas — [open the original page](https://canvas.swansea.ac.uk/courses/68227/pages/the-lidl-examples)

This is a set of example programs based on the shop Lidl.

The code is HEAVILY overcommented to include narrative explanations of what is going on - don't do this yourself!
