# 11.5 The Tenth Card Class
> [!info] From the CS-128 notes on Canvas — [open the original page](https://canvas.swansea.ac.uk/courses/68227/pages/11-dot-5-the-tenth-card-class)

Here’s the next example – we’ve changed the fields to be final.

```java
public class Card10 {

     private final String name;
     private final int value;
     private final String suit;

     public Card10(String cardName, String cardsuit) {
          //Code to set suit, name, value left out
     }

     public int getValue() {
          return value;
     }

     public String getsuit() {
          return suit;
     }

     public String toString(){
          return (name + " of " + suit);
     }
}
```
