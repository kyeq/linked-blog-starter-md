# 7.3 Summary and Exercises
> [!info] From the CS-128 notes on Canvas — [open the original page](https://canvas.swansea.ac.uk/courses/68227/pages/7-dot-3-summary-and-exercises)

In this chapter we looked at how we could avoid programs crashing if, say, we wanted integer input and the user entered non-integer data. We saw how we could 'look ahead' to see what data was waiting to be read, and throw it away if it wasn't the right type. We also saw how to use loops to re-ask the user for input until they enter correct data.

### Self-Test Quiz

Since this is a short and specialised chapter, we'll skip the quiz.

### Exercises

Go back over some of your earlier programs and add code to stop them crashing if the user enters the wrong data, and get them to ask the user to re-enter data correctly.
