# 6.10 Summary and Exercises
> [!info] From the CS-128 notes on Canvas — [open the original page](https://canvas.swansea.ac.uk/courses/68227/pages/6-dot-10-summary-and-exercises)

In this chapter we looked at the concept of a loop and the three types of loop in Java.

#### While Loop

- Has a condition and a body.
- The condition is checked and if true the body is executed - i.e. the loop will be executed zero or more times, depending if the condition is true at the start.
- This is repeated until the condition becomes false.
- While loops are used when we do not know at the start of a loop how many times it will be executed.

#### Do-While Loops

- Do-While loops have a condition and a body
- The body is executed and then the condition is checked - i.e. the loop will be executed at least once, regardless of whether the condition is true.
- Like while loops, this is repeated until the condition becomes false.
- While loops are also used when we do not know at the start of the loop how many times it will be executed, but know it will be at least once.

#### For Loops

- For loops have an initial statement (which usually declares a variable to count the number of loops or iterations - the loop counter); a condition; an end of loop operation (which is usually used to update the loop counter); and a body.
- The initial statement is executed and, if the condition is true, the loop body is executed - followed by the end of loop operation.
- This continues until the loop condition is false.
- For loops are used when the number of iterations is known at the start of the loop.

#### Other Important Points About Loops

- Make sure that the body of the loop changes the loop condition so that it eventually becomes false unless you are (very rare) writing an infinite loop on purpose.
- Good practice means you should not normally use  **break**  or  **continue**  in loops.

6. **Tricky but not a Challenge**  - you can compute the greatest common divisor (GCD) of two integers A and B like this:

	```java
	             While the value of B is not zero:
	                Set R to be the remainder of A divided by B
	                Set A to be equal to B
	                Set B to be equal to R
	```

	At the end of this process, A will contain the GCD of the (original) values of A and B. For example:

	Let A = 12 and B = 8
	B is not zero so - R = A % B = 4; A = 8; B = 4
	B (still) not zero - R = A % B = 0; A = 4; B = 0;

	So the GCD of 12 and 8 is 4 (which is correct).

	Write a program to implement GCD.
7. **Challenge** - Credit card numbers include a check digit - the last one - which helps to check if the number is ‘legal’ (that is, at least could possibly be a real credit card number - it guards against data entry errors). This is a common practice - if you applied to University via UCAS, the last digit of your UCAS number was a check digit too. Check digits are calculated in different ways - for credit cards it’s:

	Starting with the rightmost digit, add up all the alternate digit values. For example, if the number is:

	2234 5678 9876 5430

	starting at the rightmost 2, add up:
	2 + 4 + 6 + 8 + 8+ 6 + 4 + 0 = 38

	Take the remaining digits, double them, and add them up:
	3*2 + 5*2 + 7*2 + 9*2 + 7*2 + 5*2 + 3*2 + 2*2 = 82

Add the two numbers together: 82 + 38 = 120.

If the last digit of the sum (110) is zero, then the number is a legal credit card number (or at least could be - I just made this one up).
