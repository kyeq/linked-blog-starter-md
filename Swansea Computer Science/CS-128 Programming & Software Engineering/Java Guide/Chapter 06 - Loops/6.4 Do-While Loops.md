# 6.4 Do-While Loops
> [!info] From the CS-128 notes on Canvas — [open the original page](https://canvas.swansea.ac.uk/courses/68227/pages/6-dot-4-do-while-loops)

While loops are only one of three kinds of loop in Java - the next one we'll look at is the do-while loop (sometimes just called a "do loop"). The difference between an 'ordinary' while loop and a do-while loop is that a while loop checks the condition at the  **start**  (so if the condition starts off false the loop  *never*  executes); and a do-while loop checks the condition at the  **end**  (so *even if*  the condition starts off false the loop is  *always*  executed once). This point is made clear here:

> [!note] There is a video for this on the Canvas page.

These loops are very commonly used when you are getting – and checking – input; because you have to ask for the input at least once, so you know it will go around at least once. The syntax is:

```java
do {
     code
while(condition); //<-- This one DOES have a ;
```

### KEY POINT: This One  *Does* Have a ;

**Note**  – unlike the other kinds of loops (and if statements) do-while loops  **do**  have a “;” at the end. (This is frankly annoyingly unhelpful; but it is what it is.)

As an example of a do-while loop, this code repeatedly asks the user to enter a string until they enter either “yes” or “no” – this is something that you will often find useful.

```java
Scanner in = new Scanner(System.in);
String input;
do {
     System.out.print("Enter either yes or no.");
     input = in.nextLine();
} while (!input.equals("yes") && !input.equals("no"));
```

(I've put the literal strings in orange because they are important here - I won't always do that). This loop continues as long as the input is not equal to “yes”  *and* it’s not equal to “no” (so by the time it’s finished, you know it can  *only*  be one of “yes” or “no”). ### Aside: equalsIgnoreCase

One problem with the code above is that it only accepts “no” and “yes” in lower case – what about “No” or “Yes”; or “NO” or “YES”? We could check for each of these but the code would be very complex. Fortunately, we can write:

```java
...
} while (!input.equalsIgnoreCase("no") &&
    !input.equalsIgnoreCase("yes"));
```

equalsIgnoreCase checks if two strings are equal regardless of their case. Better yet, we should write something like:

```java
final String END = "no";
final String CONT = "yes";
...
} while (!input.equalsIgnoreCase(END) &&
         !input.equalsIgnoreCase(CONT));
```

By using final strings like this we can, for example, make our code independent of language. For example, by just changing two words

```java
//Language is Greek
final String END = "όχι";
final String CONT = "ναί";
...
} while (!input.equalsIgnoreCase(END) &&
         !input.equalsIgnoreCase(CONT));
```

### Using Do-While

As stated above, this kind of loop is often used to get and check user-input (because you have to ask for it at least once). However, some do prefer to use while loops for this - mostly because you often want to ask something  *slightly*  different if you need to get input the second time because of user error (for example, you might expand and/or reword the instructions you use). There are no specific 'rules' - and some programmers use do-while a lot more than others. But if you find yourself repeating code before a while loop, it's worth thinking if a do-while loop is a good idea.
