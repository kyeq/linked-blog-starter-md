# 6.2 Simple Loop Example - Skip if used to programming
> [!info] From the CS-128 notes on Canvas — [open the original page](https://canvas.swansea.ac.uk/courses/68227/pages/6-dot-2-simple-loop-example-skip-if-used-to-programming)

This section mainly back's up the video in [6.1](https://canvas.swansea.ac.uk/courses/68227/pages/6-dot-1-basic-loop-concepts) in text. Let's look at the example from section with some specific numbers - years starts at 0, and let's say we start with 1000 (say £ or €, or $ - it doesn't matter). Let's also suppose that the interest rate it 5% - so the value of MULTIPLIER is 1.05. We want to find out how long it will take to double the amount of money we have.

The first line says:

```java
while (balance < initialAmount * 2) {
```

So the condition is true - balance is less than initialAmount multiplied by 2 - which means we execute the  *body*  of the loop (the code between the {...}). So we execute these lines:

```java
balance *= MULTIPLIER;
years ++;
```

where MULTIPLIER is a constant with value 1.05. So now years is 1; and balance is 1050.

At this point, because this is a loop, the code  *goes back*  to the line:

```java
while (balance < initialAmount * 2) {
```

And tests the condition  *again* . It is still true (currentAmount is only 1050 and we need to get to 2000), so it executes the body of the loop  *again*  - this means years is now 2, and balance is 1102.5.

This continues until the condition is  *false*  - in this case, this will mean that the loop will have iterated 15 times (and years will have the value 15). At this point, balance will have the value 2078.93 (rounding to two decimal places) which, as you can see, is more than initialAmount * 2 which would be 2000.

Here is a complete program (excluding the public static void main.. part etc. which is very similar to the one from the previous section) based on this loop:

```java
//Interest rate as a %
static final double INTEREST_RATE = 5.0;
//Convert interest rate into amount to multiply money by
static final double MULTIPLIER = 1 + INTEREST_RATE/100;

//Get user input
... read in a double and store it in initialAmount

/* This loop will continue until the initial amount has doubled,
keeping track of the number of years*/
double balance = initialAmount;
int year = 0;
while (balance < initialAmount * 2) {
	balance *= MULTIPLIER;
	year++;
}

//Amount details
... output result
```

### Loop Strategy Tip

It can be difficult to start out designing loops until you have some experience - one approach is to start by thinking what code you need to do whatever computational task you need to do  *once;* and then work out what you need to do to do it  *again.* For example, in the case above, we are trying to work out how many years it will take for an amount of money to grow to a fixed target. We can start off by just working out what we need to do for  *one year:*

```java
balance *= MULTIPLER;
years = 1;
```

This tells us how much money we have after one year (and we also have a count of the number of years it has taken). Now add the calculation for a 2nd year  *without* changing the code you've written already:

```java
balance *= MULTIPLER;;
years = 1;balance *= MULTIPLER;;years = 2;
```

We can see that there is a repeated line of code - that is the first and most obvious thing to put in our loop. However, our other lines of code are not the same. Also, and unhelpfully, they set the value of years to constant values (which isn't going to help unless we know how many times we need to go around the loop - but we  *don't* know that: that's exactly what the loop is meant to find out.
