# Fibonacci Examples Illustrating Each Loop Type
> [!info] From the CS-128 notes on Canvas — [open the original page](https://canvas.swansea.ac.uk/courses/68227/pages/fibonacci-examples-illustrating-each-loop-type)

Attached are the Fibonacci examples, showing when to use each type of loop

- Your code knows how many times a loop will execute when it starts? Use a  **for**  loop
- Your code does not know? Use a  **while**  loop
- Your codes does not know, but  *does*  know it will be at least once? Use a  **do**  loop
